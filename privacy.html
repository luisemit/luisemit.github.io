Español

Esta política explica cómo FileSync, una herramienta personal de OpFlowAI, usa los datos de Google del usuario. Vigente desde el 2026-11-02.

Datos a los que accede

FileSync pide un único permiso (scope) de Google:

  • https://www.googleapis.com/auth/drive.readonly: ver y descargar los archivos de Google Drive del usuario. Es de solo lectura: FileSync no crea, modifica ni borra nada en Drive.

Cómo se usan y se guardan

  • Todo se procesa y se guarda localmente, en el equipo del usuario. FileSync usa los datos solo para copiar los archivos del usuario a su disco local.
  • Los tokens de acceso de Google se guardan en el almacén seguro local del sistema (el Llavero de macOS), no en archivos de texto.

Qué no se hace con los datos

  • Nada se comparte, vende ni transfiere a terceros.
  • Nada se envía a servidores propios ni ajenos: FileSync no tiene servidores.
  • Los datos no se usan para publicidad, ni para crear perfiles, ni para entrenar modelos de IA.

Cómo revocar el acceso

El usuario puede quitar el acceso de FileSync a su cuenta en cualquier momento en https://myaccount.google.com/permissions. Al hacerlo, el token deja de valer. Para borrar los datos locales, basta con borrar la carpeta sincronizada y la entrada del token en el Llavero.

Cumplimiento de la política de Google

El uso y la transferencia a cualquier otra aplicación de la información recibida de las API de Google cumplen la Google API Services User Data Policy, incluidos los requisitos de Limited Use (uso limitado).

Cambios

Si esta política cambia, se publica aquí con una nueva fecha de vigencia.

English

This policy explains how FileSync, a personal tool by OpFlowAI, uses the user's Google data. Effective date: 2026-11-02.

Data accessed

FileSync requests a single Google scope:

  • https://www.googleapis.com/auth/drive.readonly: see and download the user's Google Drive files. It is read-only: FileSync never creates, modifies or deletes anything in Drive.

How data is used and stored

  • All data is processed and stored locally, on the user's own computer. FileSync uses the data only to copy the user's files to their local disk.
  • Google access tokens are stored in the operating system's local secure store (the macOS Keychain), not in plain-text files.

What is not done with the data

  • Nothing is shared with, sold to or transferred to third parties.
  • Nothing is sent to any server, ours or anyone else's: FileSync has no servers.
  • The data is not used for advertising, profiling or training AI models.

How to revoke access

The user can remove FileSync's access to their account at any time at https://myaccount.google.com/permissions. After that, the token no longer works. To delete the local data, delete the synced folder and the token entry in the Keychain.

Compliance with Google policy

FileSync's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
